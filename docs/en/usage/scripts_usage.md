# Scripts Usage Guide

This document describes the functions of some scripts in the `scripts/` directory.

## **dump_latency.py**

Works in conjunction with the logging module of mcsim. It converts recorded intermediate logs into **the latency of each trace in each module** and exports the data to a specified file in CSV format. After enabling the **`DUMP_MODULEWISE_LOG`** option in mcsim to generate logs, execute `make latency` in the project root directory to call this program and generate the CSV file.

## **plot_latency.py**

Feeds the CSV file generated by `make latency` into `plot_latency.py` to obtain a **latency distribution chart for memory accesses**.

## **plot_trace.py**

Generates a **memory access address chart** for traces in the old format.

## **Trace Processing Scripts**

*   **gen_random.py**: Generates random traces.
*   **gen_sequential.py**: Generates sequential traces.

## **Batch Execution Scripts**

*   **batch_run_trace.sh**: Specifies a trace directory and runs all traces under that directory using a single mcsim executable with a specific parameter configuration.
*   **batch_run_compare.sh**: Specifies directories for mcsim executables and traces, then runs all traces under the trace directory using different mcsim executables with varying parameter configurations.
